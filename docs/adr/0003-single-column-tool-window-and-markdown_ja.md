## 背景と要件

- 現在の実装（確認済み）: ツールウィンドウは 2 列構成である（左にチャット、右に検索結果とピン留め）。回答は平文の `TextBlock` で、選択できない。入力欄には Enter/Up/Down/Tab/Escape のキーバインドが無条件に割り当てられている。
- ツールウィンドウは通常、狭い幅でドッキングされる。320px 前後では、2 列だとどちらの列にも十分な幅が残らない。
- Remote UI は XAML を Visual Studio のプロセスで実行する。コードビハインドやイベントハンドラーは使えず、独自のコントロールを参照できず、バインドできるのは `DataContract`/`DataMember` の型だけである（S1）。
- 参考拡張は、HTML を無効にした Markdig で回答を Remote UI のブロック ViewModel に変換し、ストリーミング中はその場で更新する（S2）。引用、表、リンク、文字選択には対応していない。
- Embedded の結果には複数の抽出文があり、ユーザーはそれを読んでコピーする必要がある。

## 代替案

| 案 | 要件への適合 | 利点 | コスト・リスク | 根拠 |
|--------|-----------------|----------|---------------|----------|
| 単一列の「チャット / 検索結果 / ピン留め」タブと Markdown ブロック | 完全 | 各作業で全幅を使える。回答を選択できる | タブが表示ツリーを破棄するため、状態を ViewModel に持つ必要がある | S1、S2 |
| 2 列のまま Markdown を加える | 部分的 | 変更が小さい | 320px では依然として窮屈 | 現在の XAML |
| WebView で Markdown を表示する | 低い | Markdown を忠実に表示できる | 独自コントロールなしでは Remote UI で使えない。テーマとセキュリティのコストがかかる | S1 |

## 現在の決定

- **レイアウト**: 2 列をやめ、`SelectedTabIndex` にバインドした `TabControl` 1 つにする。検索すると検索結果タブに、チャットを送信するとチャットタブに切り替える。一覧、プレビューの展開、選択は ViewModel に持つ。アクティブでないタブには新着件数を表示する。操作説明は、空のときとエラー時だけ表示する。320px でも横スクロールを出さない。
- **入力欄**: 複数行のテキストボックスとし、Enter のキーバインドは 1 つだけにして `ConfirmQueryInputCommand` で振り分ける（候補の確定か送信）。Shift+Enter で改行する。Up/Down/Tab/Esc は、候補または検索元の選択を表示している間だけバインドする。それ以外はコマンドを null にして、キーをテキストボックスに渡す。IME の変換中に送信してはならない。
- **結果カード**: タイトル、検索元バッジ（Embedded は検索元名と Preview）、秘密度ラベル、要約と、プレビュー・ピン留め・開くの操作。既存のカードのコンテキストメニュー（ピン留め、コピー、ハンドオフに追加、ブラウザーで開く）は残す。プレビューは全抽出文を選択可能なテキストで表示し、コピーもできる。開くは `ExternalUrlSafety` を通過した URL に限る。
- **Markdown**: `DisableHtml()` を指定した Markdig を使う。参照するのは net8 のプロセス外の拡張機能だけで、devenv には読み込まない。
  - ブロック: 見出し 1〜3、段落、3 段までの入れ子のリスト、引用（中のブロックも保持）、コードブロック、区切り線、および列をそろえた等幅テキストで表示するパイプ表。
  - インライン: 強調は平文にする。インラインコードはバッククォートを残す。画像は代替テキストだけを残す。HTML は除去する。
  - リンク: テキストは段落に残す。検証済みの https リンクは、回答の下にボタンとして並べる。不合格のリンクは平文のままにする。
  - ストリーミング中は、受信済みの回答全体を再解析し、ブロックをその場で更新する。閉じていないフェンスは、作成途中のコードブロックとして表示する。コピーとエディターへの挿入には元の回答を使う。
- **文字選択**: 表示専用の読み取り専用 `TextBox` スタイルを新設する。`PART_ContentHost` は `ScrollViewer` ではなく `Decorator` にし、`IsTabStop=False` にする。一覧上でのホイールのスクロールと Tab の移動は従来どおり動く。横スクロールの `ScrollViewer` を付けるのは、コードブロックと表だけにする。
- **Remote UI の契約**: 新しい ViewModel はすべて `DataContract`/`DataMember` を使う。表示の切り替えは、事前に計算した bool と `BooleanToVisibilityConverter` またはデータトリガーで行う。選択の更新では新しい項目インスタンスを送る。

## 影響と見直しの条件

- タブを切り替えるとスクロール位置は先頭に戻る。ただしチャットは最新のメッセージへスクロールする。
- コードビハインドなしでは段落内にリンクを表示できないため、リンクは各回答の下に並べる。
- Markdig はプロセス外の拡張機能の新しい依存関係になり、依存関係の監査を通る必要がある。
- Remote UI がリッチテキストや段落内のハイパーリンクに対応したとき、またはユーザーが表のセル単位の選択を必要としたときに見直す。
